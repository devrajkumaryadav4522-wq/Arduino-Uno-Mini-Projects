#PROJECT 01:
- LED Blinking using Arduino Uno


#PROJECT OVERVIEW:
- This project demonstrates digital output control using Arduino Uno. An LED is programmed to turn ON and OFF at regular intervals using Arduino programming.


#OBJECTIVE:
- TO design and implement a simple LED blinking system using Arduino Uno by controlling its digital output pin with fixed time delay.


#COMPONENTS REQUIRED:
- Arduino Uno
- Orange LED
- 220 ohms Resistor
- Breadboard
- jumper wires


#WORKING PRINCIPLES:
- Arduino Uno configures digital pin 7 as an output.
- The LED turns ON when the output is HIGH.
- The Arduino waits for 1 second.
- The LED turns OFF when the output is LOW.
- The process repeats continuously.
