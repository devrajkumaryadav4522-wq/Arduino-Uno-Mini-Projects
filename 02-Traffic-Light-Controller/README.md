# ARDUINO TRAFFIC LIGHT CONTROLLER
# Project Description
- This project implements a simple traffic light control system using an Arduino Uno and three LEDs (Green, Yellow, and Red).
- The Arduino controls the LEDs in a specific sequence to simulate a real-world traffic signal.

# Components Required
- Arduino Uno
- 1 Green LED
- 1 Yellow LED
- 1 Red LED
- 3*220ohms resistors
- Breadboard
- Jumper Wires

# Working Principle
- The Traffic Light operates in the following sequence.
- Green LED ON-5 seconds
- Yellow LED ON-2 seconds
- Red LED ON-5 seconds
- The sequence repeats continuously.
